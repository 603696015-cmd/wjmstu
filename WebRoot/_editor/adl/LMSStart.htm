欢迎使用高级分布式学习系统(ADL)
可共享内容对象参考模型 (SCORM) 1.2

本示例提供了一个ADL共享内容对象参考模型（SCORM）1.2运行环境的工作示例。这不是一个完整的学习管理系统（LMS），而是SCORM运行时间环境的一个例子，因为它可能会在一个LMS实施。

本示例包括:
  • Java applet实现的API适配器
  • SCORM运行时环境数据模型的完整实现
  • SCORM的导航数据模型的完整实现
  • 支持导入符合SCORM标准的压缩包
  • 基于IMS的简单排序规范和SCORM 1.2测序引擎

注意:本示例替换和取代的ADL示例的LMS版本1.0和2.0和示例的RTE版本1.1，1.2。
